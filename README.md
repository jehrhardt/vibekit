# vibekit

An app framework for vibe coders.

## Development

### Prerequisites

- [mise](https://mise.jdx.dev) for managing the development environment

### Setup

1. Trust the project configuration:

   ```sh
   mise trust
   ```

2. Install the required tools:

   ```sh
   mise install
   ```

3. Sync the virtual environment:

   ```sh
   uv sync
   ```
