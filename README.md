# VibeKit

An app framework for vibe coders.

## Rationale

VibeKit is being built to enable everyone — not just software engineers — to build their own applications. While there are several coding agents and application frameworks available, most require a technical background and lack deep integration with one another.

We are building VibeKit to provide an accessible framework tailored for vibe coders, bringing three core elements into a single environment:

* **Standardized Architecture:** An opinionated structure designed specifically for vibe-coded applications.
* **Optimized Harness:** A built-in agent harness tuned to the framework's architecture.
* **Spec-Driven Workflow:** A structured path to guide builders from idea to working application.
